例4 拡張機能のボタンで、1回で取り込む(Edge / Chrome)
  1. 最初に1回だけ: ブラウザの「拡張機能」→「展開して読み込み」→ フォルダ chrome-extension(このアプリと同じ場所)を選ぶ
  2. 拡張機能の「詳細」→ 「ファイルのURLへのアクセスを許可する」をオン(これを忘れると動きません)
  3. ツールバーの拡張機能(パズルの形)から、ピン留めしておく
  4. 使うとき: このアプリを開いたまま、SUUMO・ホームズ・国交省の物件ページ(または一覧)を開いて、拡張機能のボタンを1回押す
  5. ボタンに ✓(入った件数つき) / 既(すでに入っている) / ×(失敗) の印が出ます

一覧ページで、取り込みたい物件の範囲をドラッグで選んでから押すと、選んだ分だけ入ります(何も選ばなければ、ページ全体)。ホームズの一覧は先頭の20件、国交省の複数行は検討地に近い上位3件です。レインズでは使えません(貼り付けのみ)。

例5 半径800m以内だけを、印刷・PDFに載せる
  1. 「表示半径」で 800 m を選ぶ
  2. 「半径外は載せない」にチェック(地図・比較表・印刷・PDFから外側が消える)
  3. 表からも隠すなら、表の上の「半径外の行を隠す」にもチェック

チェックを外せば元どおりです(データは消えません)。

検索条件・履歴 … 入れた条件は自動で保存され、次回も残ります。サイトを開くたびに「検索履歴」に記録され、「条件を呼び出す」「もう一度開く」ができます
間違えた … Ctrl+Z で元に戻る(削除のあと)
同じ物件が2回入った … 「重複を削除」
まとめて消す … 左のチェックで選んで「選択した行を削除」
レインズの情報 … 成約は、お客様への価格の根拠に限って使えます(広告・チラシ・ネットには載せない)
保存 … 入力は自動で保存。控えは上の「PDFで保存」

物件データ入力

表形式。1物件=1行で1画面に収まります(住所を入力して確定すると自動で座標を取得。手動は「取得」、取れないときは「手入力」)。掲載URL・外観写真URL・備考欄・調べる・検討地専用項目は各行の「▸ 詳細」で表示/非表示を切替。

ページの内容から追加

  1. SUUMO・ホームズ・レインズ・国交省の、物件のページ(または一覧)を開く
  2. 全部コピー: キーボードの Ctrl+A を押して、続けて Ctrl+C
  3. 下の白い欄をクリックして、Ctrl+V(貼り付け)
  4. 「取り込む」を押す(レインズ・国交省の一覧は、全件が表に入ります)

レインズは、検索結果の一覧と、1件の詳細画面のどちらも貼れます。成約の情報は、お客様への価格の根拠として示す場合に限り使えます(広告・チラシ・ネットへの掲載は禁止)。取り込んだ内容は、行を見て直してください。拡張機能のボタンは、レインズでは使えません。
