# 周辺相場マップ

不動産の周辺相場を調べて、地図つきの表(帳票)にまとめるツールです。

## 開き方

https://hujihisahousing.github.io/market-app/

## 使い方(かんたん)

1. 「種類を選ぶ」で、土地・戸建て・マンション・テナントなどを選ぶ
2. 「検索条件」で条件を入れて、SUUMO・ホームズ・国交省などを開く
3. 物件のページを、取り込みボタン、または「ページから追加」で取り込む
4. 「物件データ」で、地図と比較表を確認し、印刷・PDFで保存する

## データについて

調べた物件は、使っている人のブラウザの中にだけ保存されます。サーバーには送りません。
人ごとにデータは別々です。

## 取り込みボタン(拡張機能)

`chrome-extension` フォルダは、Edge・Chromeの拡張機能です。
閲覧中の物件ページの文字を読んで、このツールに取り込みます。
